# Installation Guide

## Quick Start

### Step 1: Download the Extension
1. Download or clone this repository to your computer
2. Extract the files if downloaded as a ZIP

### Step 2: Load in Chrome
1. Open Google Chrome
2. Navigate to `chrome://extensions/`
3. Enable "Developer mode" (toggle in the top-right corner)
4. Click "Load unpacked"
5. Select the `chrome-extension-productivity` folder
6. The extension should now appear in your extensions list

### Step 3: Pin the Extension
1. Click the puzzle piece icon in Chrome's toolbar
2. Find "Productivity Analyzer" in the list
3. Click the pin icon to keep it visible in your toolbar

### Step 4: Start Tracking
1. Click the extension icon in your toolbar
2. The extension will start tracking automatically
3. Visit the settings page to customize categories and goals

## First-Time Setup

### Configure Categories
1. Click the extension icon
2. Click "Settings" button
3. Go to "Categories" tab
4. Add domains for each category:
   - **Productive**: Add work-related sites (github.com, stackoverflow.com, etc.)
   - **Social**: Add social media sites (facebook.com, twitter.com, etc.)
   - **Entertainment**: Add entertainment sites (youtube.com, netflix.com, etc.)

### Set Your Goals
1. Go to "Goals" tab in settings
2. Set your daily targets:
   - Productive time goal (default: 480 minutes)
   - Social media limit (default: 60 minutes)
   - Entertainment limit (default: 120 minutes)
   - Productivity score target (default: 75%)

### Customize Settings
1. Go to "Settings" tab
2. Configure:
   - Enable/disable tracking
   - Idle detection threshold
   - Notifications
   - Theme preferences

## Verification

### Check if Tracking is Working
1. Visit some websites for a few minutes
2. Click the extension icon
3. You should see:
   - Today's productivity score
   - Time spent today
   - Category breakdown
   - Top sites visited

### View Detailed Analytics
1. Click "View Details" in the popup
2. This opens the full options page with:
   - 7-day trend chart
   - Category distribution pie chart
   - Detailed site statistics
   - Historical data

## Troubleshooting

### Extension Not Tracking
- Check if tracking is enabled in settings
- Refresh the page and try again
- Make sure the extension has necessary permissions

### Data Not Appearing
- Wait a few minutes for data to accumulate
- Check if you're visiting categorized websites
- Refresh the popup interface

### Charts Not Loading
- Ensure you have an internet connection (Chart.js loads from CDN)
- Try refreshing the options page
- Check browser console for errors

### Permission Issues
- Go to `chrome://extensions/`
- Find "Productivity Analyzer"
- Click "Details"
- Ensure all permissions are granted

## Uninstallation

### Remove the Extension
1. Go to `chrome://extensions/`
2. Find "Productivity Analyzer"
3. Click "Remove"
4. Confirm removal

### Clear Data (Optional)
Before uninstalling, you can export your data:
1. Open the extension options page
2. Go to "Data & Privacy" tab
3. Click "Export Data"
4. Save your productivity data
